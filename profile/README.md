# Kizaki

*Coordination technologies for humans and agents.*

We’re building tools that let people and agents create, connect, and change software together. Our work spans collaborative workspaces and the infrastructure that keeps shared data consistent and changes accountable.

We care about software that responds immediately, works locally, and gives people control over what they make—and what happens when they share it.
